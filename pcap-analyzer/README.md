# QuickCap - PCAP Analysis Tool

A comprehensive packet capture analyzer that detects network protocols, reconstructs TCP streams, identifies routing protocols, and detects packet filtering.

## Quick Start

```bash
cd quickcap
pip install -r requirements.txt
./pcap_analyzer.py your_capture.pcap
```

See the [quickcap/README.md](quickcap/README.md) for detailed documentation.
